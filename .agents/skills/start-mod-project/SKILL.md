# Проводник старта нового мода (UUMC)

Загружай этот сценарий, если пользователь хочет сделать мод под игру, проверить совместимость игры или спрашивает, с чего начать.

## Границы возможностей (сообщай честно и простым языком)

- **Поддерживается:** игры на **Unity Mono** с **BepInEx 5**.
- **НЕ поддерживается:** игры на **Unity IL2CPP** (`GameAssembly.dll`), **BepInEx 6** и игры не на Unity.
- Если игра не поддерживается (`exit code 2` от `uumc doctor`), сразу честно скажи об этом, назови причину простыми словами и не создавай проект.

## Пошаговый сценарий общения с пользователем

1. **Естественное знакомство:**
   - Спроси только **какую игру** пользователь хочет модифицировать (и какая идея мода, если он хочет поделиться).
   - Не требуй на первом шаге технические пути, названия dev-копий, GUID или имена C#-сборок.
2. **Поиск игры на компьютере:**
   - Если пользователь указал только название игры (или не знает, где лежит папка), выполни автопоиск:
     ```powershell
     python cli/uumc.py scan --json
     ```
   - Найди совпадение по названию игры в результатах; если игр не найдено или нужная лежит в нестандартном месте, попроси вставить путь к папке с игрой (рядом с `.exe`).
3. **Проверка совместимости и готовности:**
   ```powershell
   python cli/uumc.py doctor --game-dir "<путь к игре>"
   ```
   - **Код `2` (`UNSUPPORTED`):** остановись и понятно объясни, почему эту игру сейчас нельзя модифицировать через UUMC (например, она собрана на IL2CPP вместо Mono).
   - **Код `1` (`NEEDS_SETUP`):** переведи вывод `doctor` на простой язык:
     - Советуй работать на отдельной копии папки игры, чтобы обновления Steam не ломали стенд.
     - Если не хватает `.NET SDK 8.0+` или `BepInEx 5` для Unity Mono — дай короткую пошаговую инструкцию установки (с одним тестовым запуском игры до появления `BepInEx/config/`) и дождись подтверждения пользователя перед шагом 4.
4. **Создание проекта мода (с разумными значениями по умолчанию):**
   - Предложи пользователю готовые значения по умолчанию (`папка проекта`: рядом с игрой `<GameName>Mod`, `имя мода`: `<GameName>Mod`) и уточни, включать ли локальное сохранение баг-репортов инструмента (`по умолчанию выключено`, либо сохранять локально в `reports/`).
   - После короткого согласия запусти:
     ```powershell
     python cli/uumc.py init --game-dir "<путь к игре>" --target "<папка мода>" --mod-name "<ИмяМода>" --full --report-mode <off|local>
     ```
5. **Передача пользователя в проект мода:**
   - Получи конфиг живой отладки:
     ```powershell
     python cli/uumc.py mcp --workspace "<папка мода>" --print-config
     ```
   - Объясни 3 простых следующих шага:
     1. Открой созданную папку `<папка мода>` в своей IDE как отдельный проект.
     2. Если хочешь, чтобы ИИ видел живую игру внутри, добавь показанный JSON-блок в `mcp_config.json` своей IDE.
     3. В новом окне напиши агенту: *«Помоги начать первый мод»* (запустится встроенный навык `first-run`).
