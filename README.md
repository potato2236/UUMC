# UUMC — Генератор модов для Unity-игр

Инструмент для быстрого создания, отладки и тестирования модов под **Unity (Mono + BepInEx 5)** с поддержкой ИИ-агентов.

## С чего начать

### Вариант 1: Без консоли и настройки агента (графический мастер)
1. Запусти [start.cmd](start.cmd) двойным кликом (нужен Python 3.10+).
2. Нажми **«Найти игры в Steam»** или выбери папку игры вручную — программа сразу проверит, можно ли делать мод.
3. Нажми **«Создать проект мода»**.
4. Открой созданную папку проекта в своей программе / IDE с ИИ-агентом и напиши: *«Помоги начать первый мод»*.

### Вариант 2: Сразу через ИИ-агента
1. Открой эту папку `UUMC` в своей IDE с ИИ-агентом.
2. Напиши в чат: *«Хочу сделать мод»* — сработает встроенный проводник ([start-mod-project](.agents/skills/start-mod-project/SKILL.md)), который сам найдёт игру, проверит совместимость и подготовит проект.

## Что поддерживается

- **Поддерживается:** игры на **Unity Mono** с **BepInEx 5** (`.NET Standard 2.1`, Harmony).
- **Пока не поддерживается:** игры на **Unity IL2CPP** (`GameAssembly.dll`), **BepInEx 6** и игры не на Unity. Если игра не подходит, `doctor` честно предупредит до создания проекта.

## Консольные команды (для опытных пользователей)

```powershell
# Найти игры Unity в Steam и проверить совместимость
python cli/uumc.py scan

# Проверить конкретную игру
python cli/uumc.py doctor --game-dir "../MyGameDev"

# Создать проект мода (интерактивный мастер или полный режим)
python cli/uumc.py init --wizard
python cli/uumc.py init --game-dir "../MyGameDev" --target "../MyGameMod" --full
```

Внутри созданной папки мода используется локальный лаунчер `.\uumc.cmd`:
- `.\uumc.cmd doctor` — диагностика проекта и игры.
- `.\uumc.cmd build --kill-existing` — сборка мода и копирование DLL в `BepInEx/plugins`.
- `.\uumc.cmd test --launch --kill-existing --smoke --check-log` — запуск игры в тестовом мини-окне и проверка лога.
- `.\uumc.cmd mcp --print-config` — JSON-блок для живой отладки игры из ИИ-чата.
- `.\uumc.cmd report --set-mode local` — включить (или `off` — отключить) сохранение локальных баг-репортов в `reports/`.
